# Palantir: как запустить

Это простое веб-приложение: вы открываете страницу в браузере, а программа работает на вашем компьютере. MySQL — отдельная программа, в которой можно хранить данные приложения.

Следуйте шагам по порядку. Команды можно копировать прямо из этого файла в терминал VS Code.

## Один раз настроить компьютер

### 1. Установить программы

Установите:

- **Python 3.10 или новее** с официального сайта Python. Во время установки включите пункт **Add Python to PATH**.
- **MySQL Server** и **MySQL Workbench**. Workbench — это программа с окнами и кнопками, через которую удобно управлять MySQL.

После установки MySQL его служба должна быть запущена. Если MySQL Workbench подключается к локальному серверу, значит сервер запущен.

### 2. Открыть проект и терминал

Откройте папку проекта в VS Code. В верхнем меню нажмите **Terminal → New Terminal**. Внизу появится окно, куда можно вводить команды.

Проверьте, что терминал открыт именно в папке проекта `palantir` — там, где находится этот README.

### 3. Установить библиотеки приложения

Скопируйте команду в терминал и нажмите Enter:

```powershell
python -m pip install fastapi uvicorn sqlalchemy pymysql pydantic-settings python-dotenv
```

Это устанавливает дополнительные части, необходимые Python-приложению. Эту команду обычно достаточно выполнить один раз на компьютере.

## Подготовить MySQL

### 1. Создать базу и пользователя

Откройте **MySQL Workbench** и подключитесь к своему серверу MySQL. Обычно при первом подключении вы задавали пароль пользователя `root` — введите его.

Создайте новую вкладку SQL кнопкой с листом и значком `+`. Скопируйте в нее команды ниже, затем нажмите значок молнии:

```sql
CREATE DATABASE app_db CHARACTER SET utf8mb4;
CREATE USER 'app'@'localhost' IDENTIFIED BY 'app';
GRANT ALL PRIVILEGES ON app_db.* TO 'app'@'localhost';
```

Что делают команды:

- создают пустую базу с именем `app_db`;
- создают отдельного пользователя `app` и пароль `app` для этого приложения;
- разрешают этому пользователю работать с базой `app_db`.

Если Workbench сообщает, что база или пользователь уже существуют, их не нужно создавать повторно. При желании замените пароль `app` на свой. Если меняете его, запишите новый пароль: он понадобится в следующем разделе.

## Подключить приложение к MySQL

### 1. Создать файл настроек

В терминале VS Code выполните:

```powershell
Copy-Item .env.example .env
```

Теперь в папке проекта появился файл `.env`. Откройте его в VS Code. Найдите строку `DATABASE_URL`:

```text
DATABASE_URL=mysql+pymysql://app:app@localhost:3306/app_db
```

В этой строке:

- первое `app` — имя пользователя MySQL;
- второе `app` — пароль этого пользователя;
- `localhost` — MySQL запущен на этом же компьютере;
- `3306` — стандартный порт MySQL, обычно его менять не нужно;
- `app_db` — имя базы, созданной на предыдущем шаге.

Если вы придумали другой пароль, замените только пароль в строке. Например, для пользователя `app` с паролем `secret123` адрес будет таким:

```text
DATABASE_URL=mysql+pymysql://app:secret123@localhost:3306/app_db
```

Не отправляйте файл `.env` другим людям: в нем может быть пароль. Для Git этот файл скрыт, поэтому пароль не должен попасть в общий код проекта.

## Запустить сайт

В терминале VS Code выполните:

```powershell
python -m uvicorn app.main:api --reload --port 8000
```

Если появилось сообщение `Uvicorn running`, сервер запущен. Оставьте терминал открытым и перейдите в браузере по адресу:

**<http://127.0.0.1:8000/>**

Другие полезные страницы:

- <http://127.0.0.1:8000/api/> — пример ответа сервера.
- <http://127.0.0.1:8000/docs> — список адресов API; здесь можно нажать кнопку и попробовать запрос.

Пока сервер работает, окно терминала занято — это нормально. Чтобы остановить сервер, нажмите `Ctrl+C` в этом окне.

## Что где находится

Представьте, что папка `app` — это мастерская, в которой лежат разные части сайта:

| Путь | Простыми словами |
| --- | --- |
| `app/static/index.html` | Содержимое страницы: заголовки, тексты и ссылки. |
| `app/static/styles.css` | Внешний вид страницы: цвета, размеры и расположение. |
| `app/api/endpoints/hello.py` | Пример адреса, который возвращает ответ от сервера. Новые серверные адреса добавляются здесь. |
| `app/api/deps.py` | Помощник для безопасного получения и закрытия подключения к MySQL. |
| `app/core/config.py` | Читает настройки из `.env`, например адрес MySQL. |
| `app/core/database.py` | Подготавливает подключение к MySQL для Python-программы. |
| `app/core/application.py` | Соединяет страницу сайта и серверные адреса в одно приложение. |
| `app/core/logger.py` | Записывает сообщения о работе программы. |
| `app/main.py` | Точка, с которой запускается сервер. Обычно этот файл менять не нужно. |
| `.env.example` | Образец настроек, из которого создается ваш `.env`. |
| `pyproject.toml` | Список дополнительных Python-библиотек, которые нужны проекту. |

Слова, которые могут встретиться:

- **Сервер** — программа, которая работает на компьютере и отвечает браузеру.
- **API** — адрес сервера, который возвращает данные. Например, `/api/`.
- **База данных** — место, где программа хранит информацию.
- **Пользователь MySQL** — имя и пароль, с которыми программа входит в базу.

## Как приложение использует MySQL

При запуске приложение читает адрес MySQL из `.env` и подготавливает подключение. Когда серверному адресу понадобятся данные, он сможет открыть соединение, выполнить запрос и закрыть соединение.

**Важно:** сейчас подключение подготовлено, но сайт еще не сохраняет и не загружает данные из базы. База `app_db` пока пустая. Адрес `/api/` — только пример, он возвращает заранее заданный ответ. Таблицы и функции для хранения данных добавляются отдельно, когда будет понятно, что именно нужно сохранять.

HTML-страница не соединяется с MySQL напрямую. Если на странице понадобятся данные, браузер попросит их у сервера, а сервер уже обратится к MySQL.

## Если что-то не получилось

- **`python` не найден.** Переустановите Python и включите **Add Python to PATH**. После этого закройте и заново откройте терминал VS Code.
- **`No module named ...`** — не хватает библиотеки. Повторите команду установки Python-библиотек из шага 3.
- **`Access denied`** — MySQL не принимает имя или пароль. Сверьте пользователя и пароль в `.env` с командами, которые вы запускали в Workbench.
- **`Can't connect to MySQL server`** — сервер MySQL не запущен. Запустите службу MySQL и повторите запуск приложения.
- **Не открывается сайт** — проверьте, что сервер запущен и в адресе браузера указан порт `8000`.
- **Порт `8000` занят** — запустите сервер командой `python -m uvicorn app.main:api --reload --port 8001` и откройте <http://127.0.0.1:8001/>.

## Нужно ли устанавливать Docker?

Нет. Для обычной работы достаточно Python и MySQL, установленных на компьютере. В проекте также оставлены `Dockerfile` и `docker-compose.yaml` — они нужны только тем, кто уже пользуется Docker.
